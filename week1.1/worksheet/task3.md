# Task 3

Version control systems such as Git are widely used in software development.

### State two advantages of using version control when writing software. Explain each point from:

• the perspective of an individual programmer;

• the perspective of working in a team developing software.

Answer:
As an individual programmer, Git provides you with a system that allows you to experiment with your code without the burden of file management. Stanalone branches can be created for specific features, keeping the main codebase clean and stable.

For teams, Git provide a unified codebase that all members on the team can base their work on. All commits are tied to an author and timestamp so changes can be traced back to the person who made them.

### State one disadvantage of Git. You can write this from either:

• your own perspective;

• the perspective of a new programmer who has just been introduced to it.

Answer: From the perspective of a new programmer, Git can be too low-level. It introduces abstract concepts that new users would have to learn and get used to, making its learning curve steep and unintuitive.
