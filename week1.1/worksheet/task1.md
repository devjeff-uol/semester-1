# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | list all files and directories under the current directory |
|     cd directory_name       | change the working directory to directory_name |
|     cd ..                   | change the working directory to a level above relative to the current directory |
|     cd -                    | change the working directory back to the previous one |
|     mkdir directory_name    | create a new directory named directory_name |
|     touch filename          | create a new file named filename |
|     git status              | shows general information of the active git repository |
|     git add -A              | stage all unstages changes |
|     git commit -m ""        | commit all staged changes with commit message "" |
|     git push                | push commited local changes to the remote repo |
|     git pull                | fetch changes from the remote repo and merge them to the local repo |
